About this page. CityRemedy is a PHP and MySQL application, and GitHub Pages can only host static files. This page is the project overview; the working application runs on a PHP host (link below once it is live).

How it works

Citizen

Reports a problem with a category, an address and up to four photos or PDFs, receives a Complaint ID, follows every status change, can support an existing report, and rates the repair from 1 to 5 stars.

Department officer

Signs in with an access code, sees only their own department’s queue, gives each report a validity score, creates a work order, and uploads proof of the finished work.

System

Routes each of six categories to its department automatically and fast-tracks reports that reach the community vote threshold, without bypassing the officer.
